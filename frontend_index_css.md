Title: frontend/src/index.css – Global styles and Tailwind utilities

Overview
- Imports Tailwind base, components, and utilities layers.
- Imports Inter font family from Google Fonts.
- Defines a small set of project-level utility classes used across components.

Key utilities
- .btn-primary and .btn-secondary: button styles wrapped around Tailwind utility classes.
- .input-field and .card: common input and card styles.
- Status classes used by ResultsDisplay:
  - .status-perfect
  - .status-need-steps
  - .status-wrong
  - .status-empty

Notes
- Body defaults to Inter, light background, and standard text colors.
- Avoids special graphic characters in class names and comments for portability.
