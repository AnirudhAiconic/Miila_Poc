Title: frontend/src/index.js – React entry point

Overview
- Bootstraps the React application using React 18's createRoot API and renders App inside React.StrictMode.
- Imports global styles from src/index.css.

Technologies and libraries
- React and ReactDOM.
- Tailwind CSS styles compiled from index.css and the Tailwind config.

Notes
- The index.html template from create-react-app must include a root element with id="root".
