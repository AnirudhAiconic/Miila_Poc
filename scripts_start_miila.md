Title: start_miila.bat – Quick start launcher (Windows)

Overview
- Starts the backend and frontend without running npm install or pip install.
- Intended for environments where dependencies are already installed.

Steps
1) Launches uvicorn backend on port 8000 with reload enabled.
2) Launches React dev server in frontend/.

Notes
- Use setup_and_run.bat for first-time setup or when dependencies change.
- Both windows display logs. Close either to stop that service.
